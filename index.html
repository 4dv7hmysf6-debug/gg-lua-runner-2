What this can do
This version uses a browser Lua runtime loaded from a public CDN, so internet access is needed. It executes Lua in this webpage and displays print output/errors. It does not execute Roblox Luau APIs, inject scripts into Roblox, or control a live Roblox game. For live testing, the receiving code must be built into an experience you own. Never paste code you don't trust.
